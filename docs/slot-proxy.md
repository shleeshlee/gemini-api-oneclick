# 账号代理分配

在“设置 → IP / 代理地址”中填写代理地址，可选填名称，点击“添加”。在账号弹窗的“IP / 代理分配”中选择地址，选择后立即保存；卡片显示当前分配。选择“默认代理”恢复使用 worker 的全局代理配置。

每条代理旁的“编辑”会将现有名称和地址带入输入框，点击“保存修改”更新，或“取消编辑”放弃修改。代理标识及账号分配保持不变；改地址会同步更新已绑定账号的代理，不重新登录。账号忙或保存失败时提示错误并尝试恢复原配置。

分配不重新登录、不替换 Cookie 或登录客户端。账号正在处理请求或初始化时，保存会提示稍后重试。账号重启、单号恢复和更新 Cookie 后保留已保存的分配。图片、视频、音频的生成及下载也使用该账号代理。代理库与分配接口需要面板认证，worker 接口需要管理认证。

账号弹窗两项 Cookie 都为空时，“部署”只保存账号信息，不调用部署或恢复接口。只填一项 Cookie 时不执行部署，提示完整填写；两项新 Cookie 都填写后才执行部署。

代理库保存在网关状态目录的 `proxy-settings.json`。账号文件保存 `SLOT_PROXY_ID` 和 `SLOT_PROXY`，更新 Cookie 时保留这两项；配置文件权限为 0600。迁移到另一个 worker 前会核对代理分配一致，否则保留原路由。已分配的代理需先取消分配再删除。

该功能用于 worker 模式。程序接受用户填写的代理地址，不检测出口 IP、不自动切换代理。

验证：

```sh
python -m unittest discover -s tests -v
node tests/test_panel_proxy.cjs
node tests/test_panel_login.cjs
```
